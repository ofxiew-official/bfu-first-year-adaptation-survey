# Анкета об адаптации первокурсников БФУ

Одностраничный сайт с 25 вопросами для студентов первого курса направления «Бизнес-информатика». Вопросы показаны в пяти разделах. Контактные данные респондентов не запрашиваются; открытые и чувствительные вопросы необязательны.

## Получение ответов

Форма отправляет ответы на адрес владельца через [FormSubmit](https://formsubmit.co/). При первом отправлении FormSubmit пришлёт на адрес получателя письмо с подтверждением. До подтверждения доставка новых ответов на почту не активна. Не публикуйте ссылку для студентов, пока не подтвердите адрес и не проверите тестовую отправку.

Адрес получателя указан в атрибуте `action` формы в `index.html`. После подтверждения FormSubmit позволяет заменить открытый адрес на случайный идентификатор формы (см. [документацию](https://formsubmit.co/documentation)).

## Публикация

Сайт рассчитан на GitHub Pages: источник публикации — корень ветки `main`. Сборка и серверные зависимости не нужны.

## Обработка результатов

В письме каждый ответ помечен номером и текстом вопроса. Для итогового анализа используйте план, согласованный для исследования: распределения по шкалам, сравнение нагрузки со стрессом, участия с принадлежностью, учебных трудностей с уверенностью и группировка открытых ответов по темам. Малочисленные подгруппы не следует публиковать отдельно.
